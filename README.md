## Featured Projects

### 1. VulnEra-X — AI-Powered Secure Coding Platform

**Status:** Ongoing Research

An AI-assisted static application security analysis platform designed to identify vulnerabilities and hardcoded secrets during development.

Key objectives and features

- Detect potential SQL Injection, XSS, CSRF, Command Injection, Path Traversal, Insecure Deserialization, and SSRF vulnerabilities.
- Investigate LLM-assisted reasoning to improve contextual analysis and reduce false positives.
- Generate explainable findings covering impact, root cause, and remediation.
- Prioritize risks and support developer learning through personalized feedback and adaptive quizzes.
- Compare SAST solutions including Semgrep, GitHub CodeQL, Snyk Code, Checkmarx One, and SonarQube.

**Focus areas:** Application Security · SAST · AI-assisted Analysis · Secure SDLC

### 2. Autonomous Secure P2P Networking Framework

**Technology:** Java

A decentralized peer-to-peer networking framework designed for cyber-warfare simulations and critical infrastructure monitoring.

Key features

- Applied Zero Trust principles through cryptographic challenge-response authentication.
- Secured network traffic using AES-GCM authenticated encryption.
- Implemented UDP multicast peer discovery.
- Supported automatic TCP session promotion through a Finite State Machine (FSM).
- Used TCP/UDP sockets, multithreading, and secure logging practices.

**Focus areas:** Network Security · Cryptography · Distributed Systems · Secure Communication
